# スマホ縦画面対応 — 方針メモ

- ステータス: **対応済** (2026-11-14。実機確認は利用者側で実施)
- 作成日: 2026-11-13
- 目安: 半日程度

## 方針

- **スマホは縦画面を基本**にする。ただし横に回しても遊べる (縦横どちらにも対応) ようにしておく
  - 縦: 片手で持ちやすい。iPhone ではアドレスバーが気になりにくい
  - 横: 視野が広く、館内を見渡しやすい
- PC (マウス・キーボード) の操作と表示は現状のまま

## 修正内容

| 箇所 | 現状 | 対応 | 主なファイル |
|---|---|---|---|
| 画面の向き | 横画面に固定 (最初のタップで横向きロック)。縦持ちでは「画面を横向きにしてください」を表示 | 横向きロックと縦持ちの案内を外す。ホーム画面用マニフェストの `orientation` を `any` に | `godot/web_shell.html`、`godot/scripts/touch_controls.gd`、`backend/static/brand/manifest.webmanifest`、`project.godot` (`window/handheld/orientation`) |
| 視野 | カメラは高さ基準 (`keep_aspect = KEEP_HEIGHT`) のため、縦画面では左右がかなり狭く見える | 縦長のときは幅基準 (`KEEP_WIDTH`) に切り替え、視野角も調整。タクシーの追従カメラも同様 | `player.gd`、`taxi.gd` |
| 文字・ボタンの大きさ | 1280×720 (横長) 基準で拡大縮小 (`canvas_items` + `expand`)。縦にすると幅基準で縮み、文字が小さくなる | 縦のときは基準解像度を 720×1280 相当に切り替える (画面サイズの変化を検知して `content_scale_size` を変更) | `ui.gd` (または起動時の共通処理) |
| HUD の配置 | 上部中央に読み込みバー、右上に場所表示と MENU、中央下に操作案内 | 縦用の配置を用意 (場所表示と MENU を上部に並べる、操作案内は 3/4 の高さのまま幅を狭める等) | `ui.gd`、`scenes/main.tscn` |
| モーダル | 画像と説明文を左右に並べる (作品説明)。フロアマップは横長の画像 | 縦のときは画像を上・説明を下に並べる (`HBoxContainer` → `VBoxContainer` 相当に切替)。マップは 1F / 2F を上下に並べる | `ui.gd`、`floor_map.gd` |
| スティックと視点操作 | 画面の左半分で移動、右半分のドラッグで視点 | 縦のときは画面の下側 (下 1/3 程度) の左寄りにスティック、それ以外のドラッグで視点。タップの判定は現状どおり | `touch_controls.gd` |
| タイムアタック | 結果パネル 600px 幅、タイム表示は上部中央の大きな文字 | 縦でも収まるようパネル幅・文字サイズを画面に合わせる。名前入力の +/- ボタンを大きく | `time_attack.gd` |
| デバッグ表 | 表は横スクロール可能 | そのままで可 (縦では横スクロール前提) | — |

## 実装の進め方 (案)

1. 向きの固定と縦持ち案内を外し、縦画面でそのまま動く状態にする
2. 画面の縦横を判定する共通処理を用意し、変化したら各 UI に通知する (`get_viewport().size_changed`)
3. カメラの視野 → HUD → モーダル → スティック → タイムアタックの順に縦用の配置を入れる
4. 実機確認 (iPhone Safari / ホーム画面から起動、Android Chrome) で、縦 → 横 → 縦の回転も確認

## 確認項目

- 縦・横どちらでも、文字が小さすぎず、ボタンが押しやすい (目安: タップ領域 44px 以上)
- 回転してもモーダルや HUD が崩れない
- 縦画面でスティックと視点ドラッグが干渉しない
- 縦画面でも作品の前で見上げ・見下ろしができ、展示作品が画面に収まる
- タイムアタックの運転が縦画面でも成立する (前方が見える視野)

## 対応結果 (2026-11-14)

- 向きの固定と縦持ち案内を廃止。マニフェストは `orientation: any`、`project.godot` はセンサー (6)
- 縦画面の判定は `ui.gd` (`_check_orientation`)。UI の基準解像度を縦 600x1066 / 横 1280x720 に切り替え、HUD・モーダル (画像の下に説明) を配置し直す
- カメラ: 縦は幅基準 (`KEEP_WIDTH`)。歩行 64°、タクシー 80°
- フロアマップ: 縦画面のモーダルでは 1F の下に 2F を並べた縦長 (640x1000) で描画
- スティック: 縦画面は左下 (下 45% の左半分)、それ以外のドラッグで視点
- タイムアタックは閉鎖中のため縦画面の調整は最小限 (ラベル幅のみ)
- 確認: 自動テスト (`--selftest`) 全項目合格、横 1280x720 / 縦 390x844 (タッチ表示) のスクリーンショットで確認
