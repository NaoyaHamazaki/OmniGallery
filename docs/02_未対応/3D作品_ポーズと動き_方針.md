# 3D 作品のポーズ・動き — 方針メモ

- ステータス: **保留** (2026-11-14 時点。お試しは未着手)
- 対象: 人型の骨組み (リグ) を持つ 3D 作品 (例: お試し展示のアイアンマン像。Rigify の人型リグ)

## やりたいこと

- 台座の上で回転している 3D 作品が、**1 周するごとに別のポーズへ切り替わる**
- 切り替えは 1 周後にいきなり変わるのではなく、**アニメーションでなめらかに移行**する
- ポーズの内容は Claude が作品に合わせて決める

## 動きの流れ (案)

```
ポーズ A で 1 周 → (回転を続けたまま 1〜2 秒かけて A → B へ移行) → ポーズ B で 1 周 → B → C へ移行 → … → 最初に戻る
```

- 回転 1 周の時間は現在の回転速度 (`MODEL_SPIN = 0.18 rad/s`) で約 35 秒。切り替えのタイミングは回転角が 1 周 (2π) を超えた時点
- 移行は Godot の `AnimationTree` / `AnimationNodeBlendSpace` かアニメーションのクロスフェード (`AnimationPlayer.play(name, custom_blend)`) で行う
- 3〜5 種類程度のポーズを順番 (またはランダム) に繰り返す

## ポーズの作り方の候補

| 方法 | 内容 | 長所 | 課題 |
|---|---|---|---|
| 1. 素材集から選ぶ | 汎用の人型ポーズ・動き (待機、決めポーズ、手を振る等) を用意し、Claude が作品に合うものを選んで骨組みに対応付け (リターゲット) | 品質が安定 | 骨組みの対応表が必要 (Rigify など標準的な人型ならほぼ自動) |
| 2. Claude が直接作る | Claude が関節の角度を数値で書く → Blender でポーズを作成 → 画像にして Claude が確認 → 不自然なら修正、を数回繰り返す | 作品に合わせた独自のポーズ | 静止ポーズやゆっくりした動きは現実的、複雑な連続動作は不安定 |
| 3. 動き生成の専用 AI | 文章から動きを作るサービス・モデルに Claude が指示文を渡す | 複雑な動きも可能 | 費用・規約・品質のばらつき |

今回の要件 (静止ポーズを切り替える) なら **方法 2 (または 1)** で十分。静止ポーズを複数作り、移行は Godot 側の補間に任せる。

## 必要な変更

- **変換 (`tools/convert_blend.py`)**: 現在は静止ポーズのデータは骨組みを外して書き出している。ポーズ切り替えを行う作品は骨組みを残し、各ポーズを 1 フレームのアクション (アニメーション) として書き出す
- **表示 (`gallery_manager.gd`)**:
  - 台座への載せ方 (位置・大きさ) を、骨組みのポーズを反映した形で計算する (今回の「像が浮く」問題の再発防止)
  - 回転角を監視し、1 周ごとに次のポーズへクロスフェード
- **Claude の利用**: お試しは会話中の Claude が手作業で行える。本番で自動化する場合は承認時の処理として Claude API を呼ぶ (API キーと費用の確認が必要)
- **UGC との関係**: 投稿フォーム (3.4b) に「動きをつける: おまかせ / なし」を追加する案

## 確認項目 (実装時)

- ポーズの移行中に手足が台座や柵を突き抜けない
- 移行がなめらか (急に跳ねない)、回転と同時でも違和感がない
- ポーズによって大きさが変わっても台座からはみ出さない・浮かない
- 軽量版と高品質版の両方で同じポーズ・動きになる
